## Fichiers

| Chemin | Contenu |

## Construction duotone (dans Figma)

- Cadre de l'icône : 18 × 18 (ou 12 × 12), sans fond, `viewBox="0 0 18 18"` / `"0 0 12 12"`.
- **Ton de fond** : calque vectoriel `Duo` rempli (fill), **opacité de calque 30 %** → dans le SVG exporté : `<path opacity="0.3" … fill="#888888"/>`.
- **Ton de contour** : un ou plusieurs chemins en trait (stroke) **1,5 px** (18 px) / **1,25 px** (12 px), extrémités et jonctions arrondies (`stroke-linecap="round"`, `stroke-linejoin="round"`), opacité 100 %.
- Logos (vercel, sanity, github, claude) : forme pleine unique, sans ton de fond ni trait.
- **Couleur** : chaque remplissage et chaque trait est lié à la variable **`Icon color / current`** (`VariableID:317:82`, collection « Icon color »). Cette variable a 10 modes ; le mode est posé sur un **calque parent** (le composant qui contient l'icône), jamais sur l'icône :

| Mode `Icon color` | Alias (Semantic) | Dark | Light |
|---|---|---|---|
| `default` | `icon/default` | #888888 | #555555 |
| `active` | `icon/active` | #ffffff | #111111 |
| `on-accent` | `text/on-accent` | #ffffff | #ffffff |
| `disabled` | `text/disabled` | #555555 | #888888 |
| `danger` | `icon/error` | #ee4444 | #ee4444 |
| `primary` | `icon/primary` | #0099ff | #0099ff |
| `success` | `icon/success` | #44cc66 | #44cc66 |
| `warning` | `icon/warning` | #ffd700 | #ffd700 |
| `inverse` | `text/inverse` | #111111 | #ffffff |
| `claude` | `brand/claude` | #d97757 | #d97757 |

Dans les SVG exportés, cette couleur apparaît **résolue en dur** : `#888888` (mode `default`, thème Dark) sur tous les `fill` et `stroke`.

## En faire des composants React (`currentColor`)

1. Remplacer toutes les occurrences de `#888888` (attributs `fill` et `stroke`) par `currentColor`. Garder `fill="none"` sur la racine `<svg>` et `opacity="0.3"` sur le chemin de fond : les deux tons partagent ainsi la même couleur, le fond à 30 %.
2. Retirer `width`/`height` fixes au profit d'une prop `size` (`18` | `12`) qui choisit **le jeu de tracés correspondant** (fichier racine ou `12/`) ; conserver le `viewBox`. Ajouter `aria-hidden="true"` et `focusable="false"` (icône décorative), ou un `<title>` si elle porte du sens.
3. Couleur : l'icône hérite de `color`. Poser sur le composant hôte `color: var(--k-icon-current)` ; `tokens.css` définit `--k-icon-current` (mode `default` par défaut) et les sélecteurs `[data-icon-color="active|on-accent|disabled|danger|primary|success|warning|inverse|claude"]`, équivalents du mode Figma posé sur le calque parent. Les fiches composants indiquent le mode utilisé par variante (`modes: Icon color=…`).

```tsx
// Exemple de gabarit (icône « house »)
export function IconHouse({ size = 18, ...rest }: { size?: 18 | 12 } & React.SVGProps<SVGSVGElement>) {
  return size === 12 ? (
    <svg width={12} height={12} viewBox="0 0 12 12" fill="none" aria-hidden="true" {...rest}>{/* tracés de icons/12/house.svg, #888888 → currentColor */}</svg>
  ) : (
    <svg width={18} height={18} viewBox="0 0 18 18" fill="none" aria-hidden="true" {...rest}>{/* tracés de icons/house.svg, #888888 → currentColor */}</svg>
  );
}
```

## Cas particuliers (relevés sur les calques et les SVG exportés)

- **Un seul ton (trait seul, pas de fond à 30 %)** : `plus`, `minus`, `close`, `check`, `sort`, `code`, `external`, `upload`, `eye-off`, `list-numbers`, `chevron-down`, `chevron-up`, `chevron-left`, `chevron-right`, `chevron-expand`.
- **Pleines, sans trait** : `more`, `grip` (points) et les 4 logos `vercel`, `sanity`, `github`, `claude`.
- **`loader`** : branches à opacités dégradées (100 %, 88 %, 75 %, 63 %, 50 %, 38 %, 25 %, 13 %) au lieu du duo 30 % — garder chaque `opacity` telle quelle pour l'animation de rotation.
- **Trait 1,5 conservé en 12 px** : `page`, `database`, `play` (choix du fichier Figma, pas un effet d'export).
- `fill-rule="evenodd"` / `clip-rule="evenodd"` présents dans quelques fichiers (`download`, `edit`, `file`, `image`, `locate`, `team`, `usage`, en 18 et 12 px) : les conserver.
- Dans tous les SVG, la seule couleur est `#888888` (204 `fill`, 434 `stroke`) : un remplacement global par `currentColor` suffit.
