> Route : /admin/cms/<collection> (ex. /admin/cms/blog) · Accès : Kuartz et client · Sanity : post (même écran pour Testimonials, FAQ…)

<!-- col 1 -->

### EN BREF

Les éléments d’une collection dans un tableau façon tableur (comme le CMS de Framer) : on réordonne, on modifie les cellules sur place, on ouvre la fiche complète dans le drawer (C4).

### DONNÉES

• Documents de la collection (post : title, slug, status, cover, category, date, author, excerpt, body…). Colonnes = champs affichables du schéma.
• Statut calculé depuis Sanity : Live = publié sans brouillon ; Draft = jamais publié ; Changed = publié, avec un brouillon différent.
• Ordre manuel : champ orderRank (proposé), utilisé là où le site affiche la collection dans l’ordre manuel (ex. FAQ).

### COMPOSANTS

Page header (« Blog » + « 12 posts », 4 icônes à droite), CMS cell (en-tête, poignée + case, texte, titre, statut, vignette ; état editing), Status select, Row open, barre de défilement horizontale.

### TABLEAU

• Poignée ⠿ (glisser pour réordonner), case à cocher, puis colonnes de largeur fixe : Title 240, Status 120, Slug 220, Cover 96, Category 130, Date 120, Author 150, Excerpt 320. Plus large que l’écran (1 460 px pour 1 120 visibles) → défilement horizontal, barre en bas.
• En haut à droite, 4 icônes : + nouvel élément, tri, filtre, recherche (G5).

<!-- col 2 -->

### COMPORTEMENT

• Modification directe : clic sur une cellule → édition sur place (contour bleu, curseur) ; Entrée ou clic ailleurs valide ; Échap annule. Chaque modification crée ou met à jour le brouillon.
• Statut : pastille Live / Draft / Changed avec chevron → menu selon l’état (proposé) : Changed → « Discard changes » ; Live → « Unpublish » (au prochain Publish) ; Draft → « Delete draft ». Publier un élément seul : question 3.
• Au survol d’une ligne : un bouton « open » à droite, posé sur un léger fondu de la couleur de la ligne (Row open) → ouvre la fiche dans le drawer (C4).
• Glisser la poignée : nouvel ordre enregistré (brouillon).
• Cases cochées → barre de sélection (Delete…), comme dans Media (proposé).

### ÉTATS ET CAS LIMITES

• Collection vide : « No posts yet » + « + New post ».
• Filtre ou recherche sans résultat : « No results » + Clear.
• Cellule trop longue : texte coupé avec « … » ; le contenu complet s’édite dans le drawer.
• Types non éditables sur place (image, texte riche) : clic = ouvrir le drawer sur ce champ.

### RÈGLES

Le client ajoute, modifie, supprime et réordonne des éléments ; le site les affiche déjà là où la collection est prévue. Il n’ajoute ni ne supprime de colonnes ou de champs : pas d’onglet « Fields ».
